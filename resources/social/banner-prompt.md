# BridgeClip X banner

Original logo-only design, now preserved as `bridgeclip-x-banner-logo-only.png` (1500 × 500 PNG). The current `bridgeclip-x-banner.png` features the app interface; see [its prompt and source notes](banner-app-prompt.md).

Created September 25, 2026 with the built-in imagegen tool, using `bridgeclip-x-profile.png` as the brand reference/edit target. The selected output was resized to 1500 × 500 with macOS sips.

A simple charcoal header with the gold/cyan C/play mark, the BridgeClip name, and the existing product tagline. The left side is kept clear for the profile image overlay.

Size source: [X Help — uploading profile photos and headers](https://help.x.com/en/managing-your-account/common-issues-when-uploading-profile-photo), checked September 25, 2026.

## Final prompt

```text
Use case: precise-object-edit.
Asset type: a finished X profile header banner for BridgeClip.
Input image 1: the approved BridgeClip profile image; use its gold-and-cyan C/play emblem as the exact identity to preserve while changing the canvas and layout.
Primary request: Transform the square profile artwork into a premium, very simple panoramic brand banner. Output a wide 3:1 image, ideally 1536x512, composed for a final 1500x500 X header.
Background: full-bleed, opaque near-black charcoal #101116, matching the profile picture. Flat and clean.
Composition: generous negative space. Keep the leftmost 25% mostly empty, especially the bottom-left, so the overlapping profile picture will not cover meaningful content. Place a balanced horizontal brand lockup in the middle-right of the banner: the existing gold-and-cyan C/play symbol at approximately x=480, y=250 on the final 1500x500 layout, about 190px tall; to its right, a large beautifully kerned modern geometric sans-serif wordmark "BridgeClip" starting around x=620. Under the wordmark, a smaller restrained light-gray descriptor. Keep all meaningful content between y=140 and y=345 and comfortably inside the right edge. The composition should feel deliberately balanced as a social header, not like a blown-up app tile.
Exact text:
"BridgeClip"
"Open-source AI video clipping"
Typography: BridgeClip in a confident semibold sans-serif, near-white, about 76px at final banner size. The descriptor in a quiet regular sans-serif, about 27px. Both lines left-aligned, clear and spelled exactly. No other text.
Identity invariants: preserve the same C silhouette, gold upper-left folded ribbon, cyan lower ribbon, and centered cyan right-pointing play triangle from the reference. Preserve the colors. Use the symbol once, without its original square canvas or any border.
Avoid: extra logos, X logo, website addresses, slogans beyond the exact provided text, UI screenshots, filmstrips, tiny decorative details, badges, gradients, glows, 3D, drop shadows, frames, rounded-square tiles, mockup interface, watermarks, photographic elements. Produce only the finished banner.
```
